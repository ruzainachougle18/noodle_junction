# 🍜 Noodle Junction

A responsive Asian-inspired noodle restaurant website built using HTML, CSS and Bootstrap 4.4.1. The website features a stylish layout, food sections, navigation, image galleries and a restaurant-themed design.

## 📌 About the Project

Noodle Junction is a restaurant website project designed to showcase a variety of noodle dishes, flavours and signature bowls. It features a clean layout, attractive food imagery and a dark, premium-inspired design with complementary colours.

## ✨ Features

- Responsive navigation bar with hamburger menu
- Search bar in the header
- Image carousel
- About Us section
- Customer favourites section
- Signature menu section
- Noodle, flavour and add-on selections
- Specials page
- Gallery page
- Contact page
- Hover effects and image transitions
- Responsive layout using Bootstrap

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 4.4.1
- jQuery
- JavaScript

## 🎨 Design

The website uses a combination of dark charcoal, deep teal, warm ivory, gold and lime accents to create a modern restaurant-inspired appearance.

## 📂 Pages

- Home
- Our Menu
- About Us
- Specials
- Gallery
- Contact Us

## 🚀 Getting Started

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use Live Server.
